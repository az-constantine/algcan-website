# ALGCAN IMPORT INC. — Static Website

Première version du site vitrine bilingue FR/EN.

## Fichiers
- `index.html` — structure complète du site
- `style.css` — design responsive
- `script.js` — menu mobile et changement FR/EN
- `assets/logo.jpg` — logo fourni

## Informations actuellement intégrées
- Domaine : www.algcan.com
- Courriel : info@algcan.com
- Téléphone : à ajouter
- Adresse : à ajouter

## Mise en ligne
Le projet est conçu pour être hébergé comme site statique sur Azure.
Aucune base de données ou serveur applicatif n'est nécessaire pour cette première version.

## À prévoir ensuite
- Remplacer le hero générique par une vraie photo professionnelle d'importation/agroalimentaire.
- Ajouter les vrais produits et photos dans le catalogue.
- Ajouter téléphone et adresse.
- Connecter le formulaire à un service d'envoi réel (le `mailto:` actuel ouvre le client courriel).
- Configurer le domaine `www.algcan.com` et le HTTPS dans Azure.
- Ajouter les métadonnées SEO, Open Graph et éventuellement Google Analytics/Matomo.
